# 3D Scripts/Tools

Allows the user to execute 3D cli commands and leverage the output to develop
helper scripts.


# Setup
```
./dev_setup.sh
```

# Examples
Examples can be found in the ```/cli_examples``` directory. They can be executed
via python commands OR preferred IDE.

Python CLI ex:
```
$ python cli_examples/example_advisor_descriptor.py
$ python cli_examples/example_properties_descriptor.py
$ python cli_examples/example_solve_expression.py
```
